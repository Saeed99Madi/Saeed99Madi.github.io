# Social profile copy

Drafts to paste into each platform. Written for the people reading those
profiles, not for you — so the tone differs from the portfolio site.

| File | Platform |
| --- | --- |
| [linkedin.md](linkedin.md) | Headline, About, experience entries, Featured, skills |
| [upwork.md](upwork.md) | Title, overview, portfolio items, specialisations |

**GitHub is already done** — profile fields and the profile README were updated
directly through the API. The only thing left there is pinned repositories,
which have no API and must be set in the browser.

## Why these are drafts rather than automated

LinkedIn and Upwork both detect browser automation and restrict accounts for
it. Your LinkedIn is a professional asset; risking a lock to save ten minutes
of pasting is a bad trade. GitHub is different — it has a real API, and
everything done there is reversible through git.
